# SmartEcoCity

Адаптивный сайт для жителей Кыргызстана (mobile-first).

## Запуск локально

1. Скачайте папку `smart-eco-city`.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari).
3. Готово! Сайт работает полностью на клиенте (демо-режим).

Для удобства можно запустить простой сервер:

```bash
# Python
python -m http.server 8000
# или Node
npx serve .
```

Затем откройте http://localhost:8000

## Где разместить

### Быстрый вариант (только фронтенд)
- **Netlify**: перетащите папку на netlify.com/drop
- **Vercel**: `npx vercel` или через GitHub
- **GitHub Pages**: загрузите в репозиторий и включите Pages
- **Cloudflare Pages**

### Полноценный вариант с бэкендом
1. Фронтенд: Vercel или Netlify
2. Бэкенд (Node.js/Express или Python/FastAPI): Railway, Render, Fly.io
3. База: PostgreSQL на Supabase, Neon, или Railway
4. Почта: SendGrid или Resend
5. SMS/WhatsApp: Twilio
6. ИИ: OpenAI API или Grok API для анализа текста

## Админ-панель
В текущей демо-версии данные хранятся в localStorage браузера.
Для продакшена нужна отдельная админка для:
- Редактирования базы чиновников (область, город/село, должность, ФИО, email, телефон)
- Добавления новостей
- Просмотра обращений и смены статусов

## Логотип
Замените блок с буквой «S» в шапке на:
```html
<img src="logo.png" alt="SmartEcoCity" class="w-10 h-10" />
```
И загрузите свой файл `logo.png` рядом с `index.html`.
